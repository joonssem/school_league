## 2. 아이패드 9·10세대 하드웨어 최적화 검증

1. **더블탭 및 핀치 줌 방지**:
   - `viewport-fit=cover`, `user-scalable=no`, `touch-action: manipulation` 적용으로 학생 연타 시 화면 흔들림 원천 차단.
2. **동적 뷰포트 높이 (`100dvh`)**:
   - 사파리 주소창 높낮이 변동에 영향받지 않고 완벽한 풀스크린 레이아웃 유지.
3. **PWA 홈 화면 추가 지원**:
   - `apple-mobile-web-app-capable` 및 다크/라이트 상태바 대응으로 아이패드 바탕화면에 앱 아이콘 등록 시 Safari 툴바가 사라진 독립 앱 형태로 실행.
4. **네트워크 호스트 개방 (`vite.config.ts`)**:
   - PC에서 `npm run dev` 실행 시 로컬 IP가 노출되어, 같은 와이파이에 연결된 아이패드에서 즉시 접속하여 테스트 가능.
