# [기술 명세서] 아이패드 9세대 및 10세대 환경 최적화 설계

- **작성일자**: 2026-09-16
- **대상 기기**: Apple iPad 9세대 (10.2형), iPad 10세대 (10.9형)
- **주요 브라우저/환경**: iPadOS Safari, 홈 화면 추가 PWA(Standalone 모드)
- **작성자**: 리드 사이언티스트 & 테크니컬 오너

## 2. iPadOS WebKit 환경 필수 고려사항 및 해결 전략

### 2.1. 동적 주소창 및 툴바 이슈 방지 (100dvh 적용)
* **문제점**: iPad Safari는 스크롤이나 터치 시 주소창 및 하단 툴바가 가변적으로 줄어들거나 늘어나 `100vh` 사용 시 하단 콘텐츠가 잘림.
* **해결책**:
  * CSS 최신 표준인 `100dvh` (Dynamic Viewport Height) 적용.
  * `h-screen h-[100dvh]` 및 `overflow-hidden` 레이아웃 구조로 전체 스크롤 덜컥거림을 완전 차단.

### 2.2. 터치 제스처 오작동 방지 (Pinch-to-Zoom & Double-Tap 차단)
* **문제점**: 초등학생들이 태블릿 화면을 연타하거나 점수를 급하게 누를 때 화면이 확대되거나 튕기는 현상 발생.
* **해결책**:
  * Viewport 메타태그: `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover">`
  * CSS 전역 터치 조작 제한: `touch-action: manipulation;` 및 `-webkit-touch-callout: none; user-select: none;`

### 2.3. 입력 폼 자동 줌 인(Auto-Zoom) 방지
* **문제점**: iOS Safari는 폰트 크기가 `16px` 미만인 입력창 포커스 시 자동으로 화면을 줌인하여 레이아웃이 깨짐.
* **해결책**: 모든 입력 필드의 기본 폰트 크기를 최소 `16px` 이상(키패드는 24px~32px)으로 설정.

### 2.4. 터치 타깃 규격 (Apple HIG 준수 및 초등학생 맞춤)
* Apple 권장 최소 터치 규격(44×44pt)을 넘어, 초등학생의 조작 편의를 위해 **키패드 버튼 최소 64×64pt 이상, 대기열 카드 높이 최소 56pt 이상** 확보.
* 터치 피드백 강화 (`active:scale-95`, `active:bg-amber-200` 등 햅틱 느낌의 즉각적 시각 반응).

### 2.5. 안전 영역(Safe Area Insets) 대응
* iPad 10세대의 둥근 모서리와 제스처 바를 고려하여 `padding: env(safe-area-inset-top) env(safe-area-inset-right) env(safe-area-inset-bottom) env(safe-area-inset-left)` 적용.

## 3. 아이패드 화면 모드별 UI 레이아웃 전략

### 3.1. 가로 모드 (Landscape) - 기본 권장 (거치대/키보드 장착 시)
* **2열 분할 레이아웃**:
  * **좌측 (55~60%)**: 대기열 현황 (진행 중인 경기 + 줄 서 있는 대기열 카드)
  * **우측 (40~45%)**: 대형 점수 입력 키패드 및 바로가기 컨트롤
* 시선 이동을 최소화하고, 한 화면에서 대진 파악과 점수 입력을 동시에 해결.

### 3.2. 세로 모드 (Portrait) - 휴대 시
* **탭 전환형 단일 열 레이아웃**:
  * 상단: 진행 경기 요약 바
  * 본문: 대기열 ↔ 점수 입력 모달 ↔ 순위표 전환

## 4. '홈 화면에 추가'를 통한 네이티브 앱화 (PWA Standalone)

아이패드 Safari에서 **[공유] → [홈 화면에 추가]**를 하면:
1. 주소창과 Safari 툴바가 100% 제거되어 전체 화면이 앱처럼 실행됨.
2. 학생들이 다른 웹사이트로 이탈할 수 없음.
3. 오프라인 캐싱(Service Worker)을 연계하여 체육관에서 와이파이가 끊겨도 완벽 구동.
