## 2. 세부 검증 (3대 영역별 보안 분석)

### 2.1. 깃허브 저장소(GitHub Repository) 소스코드 노출 여부
* **위험 요인**: 깃허브 저장소가 공개(Public)일 경우, 코드에 실제 학생 명단이 포함되어 있으면 누구나 볼 수 있음.
* **본 프로젝트의 보호 조치**:
  1. 실제 학생 명단은 코드 파일에 하드코딩되지 않으며, 앱 실행 후 웹 화면에서 나이스 복사-붙여넣기로 입력됨.
  2. 코드에 포함된 예시 데이터(`src/utils/mockData.ts`)는 대법원 통계 다빈도 출생명을 기반으로 한 **100% 가상 더미 데이터**임.
  3. [`.gitignore`](file:///D:/Projects/school_league/.gitignore)에 엑셀(`*.xlsx`), 출석부 텍스트(`*.csv`), 백업 파일(`*.json`), 데이터 폴더(`primary_data/`, `secondary_data/`)를 등록하여 실제 명단 파일이 깃허브로 업로드되는 것을 원천 차단함.

### 2.2. 배포된 웹사이트(URL) 접속 시 타인 노출 여부
* **위험 요인**: 배포된 주소(`https://xxx.github.io`)를 다른 사람이 열었을 때 우리 반 학생 명단이 보일 것인가?
* **검증 결과: 절대 볼 수 없음.**
  * 본 앱은 중앙 데이터베이스(DB)가 없는 **브라우저 로컬 스토리지(`localStorage`) 기반**입니다.
  * 데이터는 오직 **선생님 아이패드의 사파리 메모리 내부**에만 저장됩니다.
  * 다른 사람(학부모, 학생, 외부인)이 해당 주소로 접속하면, 그 사람 기기에는 아무런 데이터가 없는 초기 상태만 로드됩니다.

### 2.3. 교실 내 전자칠판/아이패드 화면 노출 여부
* **위험 요인**: 교실 전자칠판에 띄웠을 때 학생들이 다른 친구의 등수나 실명을 보고 서열화/놀림 발생 가능성.
* **본 프로젝트의 보호 조치**:
  * **'교실 화면 (전자칠판 모드)'** 탑재:
    * 1등~26등과 같은 등수를 완전히 숨기고 등급(골드, 실버)으로만 묶어 표시.
    * 이름 가운데 글자를 자동 마스킹 (`강○준`, `김○윤`)하여 개인정보 보호.
    * 조작 버튼을 제거하여 학생 터치 시 데이터 변형 방지.
